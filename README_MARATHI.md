# QR-Based Menu and Food Ordering System

## Project Overview

The QR-Based Menu and Food Ordering System is a web-based application developed using PHP, MySQL, HTML, CSS, and JavaScript. It allows customers to view a restaurant menu, add food items to the cart, and place orders online.

The system also provides an admin panel to manage menu items, view customer orders, and update order statuses.

## Objectives

- To provide a digital menu using a web application.
- To make food ordering simple and convenient.
- To reduce manual order-taking work.
- To help restaurant staff manage orders efficiently.
- To provide an easy-to-use interface for customers and administrators.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Local Server:** XAMPP
- **Version Control:** GitHub

## Main Features

### Customer Module
- View the food menu.
- Select food items and quantities.
- Add items to the cart.
- View the order total.
- Enter customer and table details.
- Place an order.

### Admin Module
- Log in to the admin panel.
- View customer orders.
- Manage menu items.
- Update order statuses.
- Monitor orders through the dashboard.

## Installation and Setup

1. Install XAMPP on your computer.
2. Start Apache and MySQL from the XAMPP Control Panel.
3. Copy the project folder into the `htdocs` directory.
4. Open phpMyAdmin and create the database using the provided `database.sql` file.
5. Check the database connection settings in `db.php`.
6. Open the project in your browser using the appropriate localhost URL.

## Project Purpose

This project demonstrates how a restaurant can use a digital system to display its menu and manage food orders efficiently.

## Conclusion

The QR-Based Menu and Food Ordering System provides a simple and convenient way to browse food items and place orders. It also helps administrators manage menu items and customer orders through a centralized web application.
