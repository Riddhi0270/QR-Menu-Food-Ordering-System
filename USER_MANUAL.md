# User Manual

## Customer
1. Open the application menu URL.
2. Browse the available food items and prices.
3. Choose a quantity and click Add to Cart.
4. Review the cart and total amount.
5. Enter your name and table number.
6. Click Place Order.
7. Note the order number shown on the confirmation page.

## Administrator
1. Open `/admin/login.php`.
2. Enter the admin username and password.
3. Open the Orders dashboard to view orders.
4. Select a status and click Update.
5. Open Manage Menu to add items or toggle availability.
6. Log out when finished.
